🚗 BMW Sales Analysis Dashboard
🧾 Executive Summary

This project provides a detailed analysis of BMW’s sales performance across various regions and models, focusing on pricing, mileage, and sales distribution by model, region, and fuel type.

The analysis was conducted using Microsoft Excel, with Power Query for data transformation, Pivot Tables for summarization, and an interactive dashboard for visualization.

🎯 Project Aim

The main objectives of this project were to identify:

A. 🔝 Top 5 BMW models by price in Europe.
B. 🏆 BMW model with the highest sales volume in 2016.
C. 🚘 BMW model with the highest average mileage (for grey-colored models).
D. 🌍 Region with the lowest sales volume.
E. ⚡ Region with the highest sales volume of hybrid fuel type models.
F. ⚙️ BMW model with the highest sales volume using manual transmission.

🧰 Tools & Technologies Used

Microsoft Excel

Power Query (for data cleaning and transformation)

Pivot Tables (for data summarization)

Charts and Dashboards (for visualization and insights)

🧹 Data Preparation & Transformation

Data cleaning and transformation were carried out using Power Query to ensure accuracy and clarity before analysis.

Key Steps:

✅ Renamed columns for readability and consistency.

💲 Added currency format to price-related fields.

🚫 Removed errors and null values to maintain data integrity.

🔢 Created calculated fields (e.g., average mileage, total sales).

📊 Transformed dataset to enable Pivot Table creation.

After transformation, the cleaned dataset was loaded into Excel, where Pivot Tables were built to summarize results. An interactive dashboard was then designed using charts, slicers, and filters for clear data storytelling.

📈 Key Insights Extracted
💰 Top 5 BMW Models by Price (Europe)

BMW i8

BMW i3

BMW 3 Series

BMW 5 Series

BMW M5

➡️ Insight: The BMW i8 leads as the most expensive model in Europe, with the BMW M5 as the least in the top five.

🏆 Highest Sales Volume by Model (2016)

BMW 3 Series recorded the highest sales volume in 2016.

🚘 Highest Average Mileage (Grey Color)

BMW M5 had the highest average mileage of 102,343 km among grey-colored models.

🌍 Regional Insights

Lowest Sales Volume: South America

Highest Hybrid Fuel Type Sales: Asia

⚙️ Highest Manual Transmission Sales

BMW 7 Series recorded the highest sales volume with manual transmission.

🧠 Business Recommendations

Based on the analysis, the following actions are recommended:

🌎 Conduct regional market research to understand the factors driving low sales in specific regions like South America.

⚙️ Implement strategies to reduce high car mileage through:

Regular vehicle maintenance programs

Driver education initiatives

Improved fuel efficiency measures

Routine vehicle inspection campaigns

💡 Leverage hybrid technology in regions like Asia, where hybrid models show high adoption rates.

🚀 Capitalize on successful models such as the BMW 3 Series and BMW i8 to drive marketing and product strategy decisions.
